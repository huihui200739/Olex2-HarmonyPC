# Python 多行编辑与脚本文件入口

日期：2026-11-10。当前集成版本 **0.22.37 / 223700**。

## 本批真正新增的可用功能

- 工作台和工具菜单都能打开多行脚本编辑器；支持保留缩进、中文和多行输入。
- 通过鸿蒙系统文件选择器打开 UTF-8 `.py` / `.txt` 文本，或者将草稿另存为 `.py`。
- 文件上限为 **64 KiB UTF-8 字节**，不是按字符数冒充字节限制。支持去除一个开头 UTF-8 BOM；无效编码、NUL、超限、未完成写入会返回错误，不替换原草稿。
- 保存处理短写，完成后回读逐字节核对；文件选择取消会保留当前草稿。保存失败会提示目标文件可能未写完，不擅自删除用户文件。
- 打开文件**不会自动执行**。只有点击“运行脚本”，才调用34已有的同一个原应用 Python VM 和原桥接。
- 关闭编辑器返回工作台不丢失本次会话草稿；程序重启前仍须另存为。本批没有实现跨重启草稿恢复。

## 两个实际发现和修正

- **35**：构建与来源验证成功；编辑器打开时零延迟焦点请求早于控件创建，出现普通UI生命周期错误150003并退出。保留原JS崩溃记录；没有重复触发，没有执行脚本。36改用已挂载TextArea的默认焦点。

- 35/36原源码与完整构建在本机保留；Git备份提供相对37完整快照的逐字节/权限核对历史覆盖层，不把失败记录改成成功。

## 构建与交付边界

- 37共839个真实原生编译单元，含221个源码重编Python C单元；6978个捕获输入、2629个依赖、3份包内原生库，实际构建来源核验通过。

- 固定上游C++构建纳入仍为 **381/442＝86.20%**，不是整体功能完成率。
- 这是**载入脚本文本后在同一VM执行**，尚未实现完整文件模块语义：真实脚本文件名回溯、`__file__` / `sys.argv` / 相对模块搜索上下文、原Run/Reset宏等不可据此视为完成。
