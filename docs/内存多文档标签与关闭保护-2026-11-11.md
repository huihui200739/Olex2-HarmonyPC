## 实现范围：有界内存标签，不是多个原生实例

| 边界 | 当前含义 |
|---|---|
| 标签数量/来源预算 | 最多4文档，来源文本合计32MiB，单份8MiB；不是整个进程内存上限，也不是草稿/history的合并预算 |
| 独立上下文 | 每份有独立ID、实际草稿、撤销/重做history、查找/替换及编辑状态；重名不合并文档 |
| 原生所有者 | 只有一个native active TGXApp；切换在该原生文档槽重载所选来源并重新绑定编辑器，不是4个原生owner同时驻留 |
| 原生绑定 | 普通选择变化不改变来源/native所有权；这不等于保存或恢复各标签相机/选择 |
| 打开取消/容量 | 真实新开选择器取消不增标签、不丢原草稿；第五打开在选择器/native加载之前拦截并提示 |
| 独立编辑/应用 | A撤销/重做不改B；B的普通人工标签实际应用后，切换返回仍保持“已应用但未保存”状态 |
| 非活跃关闭 | 关闭确认明确指向目标文档；取消/显式丢弃不误关当前原生文档；关闭干净非活跃项不调用native Close |
| 活跃/最后关闭 | 先实际关闭活跃项，再实际重载邻项；最终关闭后的registry/cache/controller/history退休由独立只读记录确认 |

容量数字是实现契约：`snapshots/source54/app/entry/src/main/ets/model/OriginalDocumentSessions.ts` 与 `snapshots/source54/app/entry/src/main/ets/model/OriginalDocumentTransfer.ts`。设备证据验证四标签/第五拦截，不声称8MiB/32MiB满载边界、全部异常路径均已设备实测。
