## 取回方式

```bash
# 1) 用 bundle 建一份旧历史仓库（不动当前工作目录）
git clone ~/Documents/鸿蒙pc适配/OleX2-pre-slim-2026-11-17.bundle olex2-old

# 2) 只取某个收据/截图
cd olex2-old
git log --oneline --all | head
git checkout pre-tidy-2026-11-17 -- experiments/original-document62/cpp442-main-gui-v1/toolbar-actions-v1/validation-v2.json

# 3) 把某个目录整份导出到 /tmp
git archive pre-tidy-2026-11-17 experiments/original-document62 | tar -x -C /tmp
```

校验 bundle 是否完好：

```bash
shasum -a 256 OleX2-pre-slim-2026-11-17.bundle
git bundle verify OleX2-pre-slim-2026-11-17.bundle
```
