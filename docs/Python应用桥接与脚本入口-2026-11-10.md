- 将固定CPython3.11.18的221个C编译单元重新编入唯一原核心DSO，没有把独立运行时的预编译Python库放入HAP。

- Python owner在原应用析构前释放，并在VM/GIL仍有效时清理原Python变量单例。**本批没有验证正常关闭/重启或任意线程析构，不把生命周期代码存在当作这些流程已验收。**
